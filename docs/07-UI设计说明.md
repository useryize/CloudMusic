# 云音乐 PC 端 UI 设计说明

> 画布：https://ardot.tencent.com/file/746887555940159
> 版本：v1.0 · 2026-11-16
> 范围：15 个 1440×900 画板，深色主题，PC 客户端（Windows / macOS 通用布局）
> 配套文档：`01-接入与鉴权.md` ~ `06-完整接口索引.md`、`接口能力说明.html`

---

## 0. 这份文档讲什么

本文档说明画布上 **15 个界面**分别长什么样、由哪些模块组成、每个数据位该填什么、以及**该位对应哪条官方开放接口**。

三条原则贯穿全部设计：

1. **每个数据位都有来源**。凡是界面上出现的列表、封面、数字、按钮，都标注了对应接口；没有接口支撑的元素一律不画（本轮已删除侧栏「创建的歌单 +」、我的音乐「编辑资料」等 4 处）。
2. **骨架只有一套**。除「播放页」和「登录授权」外，13 个页面共用同一套 220 / 64 / 748 / 88 的框架，页面之间只有内容区不同。
3. **只做设计，不含切图**。画布里是可编辑的矢量节点，没有导出 PNG/切图素材，也没有标注图；开发需要的尺寸、色值、字号全部在本文件里。

接口路径均省略统一前缀 `https://openapi.music.163.com`，参数走公共参数（`appId` / `accessToken` / `signType` / `timestamp` / `device` / `sign`）+ `bizContent` 的 JSON 字符串，详见 `01-接入与鉴权.md`。

## 2. 设计规范

### 2.1 全局骨架

除播放页、登录授权外，全部页面使用同一栅格：

```
┌────────┬──────────────────────────────────────┐
│ 侧栏    │ 顶栏 1220 × 64                        │  ← y = 0
│ 220    ├──────────────────────────────────────┤
│ × 812  │ 内容区 1220 × 748（padding 32）        │  ← y = 64
│        │                                      │
├────────┴──────────────────────────────────────┤
│ 播放条 1440 × 88                               │  ← y = 812
└───────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 说明 |
|---|---|---|
| 侧栏 | 220 × 812 | 固定，Logo 40 + 4 个导航项（各 40）+ 分隔线 1 + 歌单标题 30 + 歌单项 36 + 弹性占位 + 设置 36 |
| 顶栏 | 1220 × 64 | 后退/前进 30、搜索框 340 × 36、弹性占位、音质标签 + 头像 30 |
| 内容区 | 1220 × 748 | padding 上下左右各 32，模块纵向 gap 18（部分页面按需 20 / 24，见各页说明），`clipsContent` 开启 |
| 播放条 | 1440 × 88 | 当前播放 280 × 56、控制区（按钮组 34 + 进度条 460 × 14）、右侧工具栏 200 × 56 |

内容区实际可用宽 1156（1220 − 64），所有多列卡片横向间距据此计算，例如 5 列卡片 = `(1156 − 4×18) / 5 = 216.8`，实际取 218（发现音乐）、200 见方（歌单广场封面）。

**两个例外**：

- **播放页** `7:1`：无侧栏、无顶栏，1440 全宽沉浸式。主区 1440 × 700 + 底部控制 1440 × 128，背景有一层 1440 × 540 的主色径向光晕。
- **登录授权** `12:874`：只有一个 420 宽居中卡片，背景光晕直径 600。

### 2.2 色彩

所有颜色为 SOLID 填充，不带透明度（除覆盖层气泡）；渐变为 LINEAR 两段停止点。

| Token | 色值 | 用途 |
|---|---|---|
| `bg/base` | `#0B0D10` | 页面底色（内容区背景） |
| `bg/panel` | `#0F1114` | 侧栏、顶栏、播放条面板 |
| `bg/raise` | `#131519` | 抬升卡片（登录卡、播放卡、榜单卡） |
| `bg/input` | `#16181D` | 输入框、分段控件底 |
| `bg/card` | `#1B1E24` | 歌单卡 / 按钮默认底 |
| `bg/avatar` | `#2A2E36` | 头像占位、标签选中底、进度条轨道 |
| `line` | `#24272E` | 描边、分隔线 |
| `brand` | `#EC4141` | 主色：播放全部、选中态、发送、当前播放标识 |
| `text/primary` | `#E6E8EC` | 标题、正文 |
| `text/second` | `#C9CDD4` | 次级正文（歌曲名、昵称） |
| `text/tertiary` | `#9AA0AA` | 次要信息（歌手、副标题） |
| `text/muted` | `#646A75` | 弱化信息（时长、播放量、表头） |
| `text/disabled` | `#4A4F58` | 序号、极弱提示、协议行 |

封面一律用 `GRADIENT_LINEAR` 双色渐变占位（每张不同色相，用于区分），不使用位图。

### 2.5 间距与圆角

- 内容区外 padding 32；模块之间 18（首页/歌单）到 24（我的音乐/播客）。
- 分区标题与内容间距 10 ~ 14；表头与首行间距 0（靠行高留白）。
- 卡片圆角：封面 8 / 10，卡片 12，登录卡 16，按钮与标签为高度一半（胶囊）。
- 分隔线统一 1px `#24272E`，只在"表头下"和"头部下"出现，列表行之间不画线。

**全局性事实（三次核对都成立）**：

1. **没有"新建歌单"接口**，只能往已有歌单批量塞歌（`playlist/song/batch/like`）。所以侧栏 9 个画板上的 `+` 已全部删除。
2. **没有上传歌曲接口**，也没有动态/私信/粉丝接口——对应产品功能无法做。
3. **MV 只有列表/详情/搜索，没有播放地址**；音频播放地址有，但短时效、禁缓存。
